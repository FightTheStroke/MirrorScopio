# Dyslexia-Friendly Fonts Licenses

This directory contains open-licensed, dyslexia-friendly fonts intended to improve readability for users with dyslexia and visual processing differences.

## Usage Notes

- **macOS Integration:** These .otf and .ttf files can be installed system-wide by copying them to `~/Library/Fonts/` or by double-clicking the font file in Finder
- **Embedded Use:** The fonts can be embedded in macOS applications and are suitable for use in UI frameworks like SwiftUI and UIKit
- **Accessibility:** These fonts are optimized for users with dyslexia, low vision, and other visual processing differences
